# EXIF-Editor

Foto-Metadaten ändern, komplett im Browser. Die Fotos werden nicht hochgeladen, alles läuft lokal.

- Handy-Vorlagen mit realitätsnahen EXIF-Feldern pro Marke (iPhone, Samsung, Pixel, Android)
- Einzelne Felder, Datum/Uhrzeit und GPS lassen sich ein- und ausschalten
- Handy-Vorschau mit Zuschnitt, Drehen und Formatanpassung

Eine einzige Datei: `index.html`. Zum Ausprobieren einfach im Browser öffnen oder über GitHub Pages ausliefern.

## Als App installieren

Nach dem Aktivieren von GitHub Pages ist die Seite eine installierbare Web-App mit eigenem Symbol und Offline-Cache.

- **iPhone (Safari):** Teilen, dann „Zum Home-Bildschirm“
- **Android (Chrome):** Menü, dann „App installieren“
- **Computer (Chrome/Edge):** Installieren-Symbol in der Adressleiste
